## Institutional Collection Management System

A web-based institutional debt and payment collection management system developed using **ASP.NET Core MVC, C#, Entity Framework Core, and SQL Server**.

The application provides a centralized platform for managing institutions, customers, outstanding debts, and payment transactions through a secure, role-based architecture.

## Key Features

- **Role-Based Authentication:** Separate administrator and customer interfaces using ASP.NET Core Identity.
- **Institution & Customer Management:** Manage institutional accounts, customer records, and collection products.
- **Debt & Payment Management:** Track outstanding debts, process payments, and monitor transaction history.
- **Dashboard & Reporting:** Interactive dashboards, financial summaries, and transaction reports.
- **AI-Powered Assistant:** Integration with Ollama for conversational user assistance.
- **Machine Learning Integration:** ML.NET-based functionality for data analysis.
- **REST API:** API endpoints for debt-related operations, tested using SoapUI.
- **Audit Logging & Notifications:** Track system activities and manage payment-related notifications.
- **PDF Receipts:** Generate downloadable receipts for completed transactions.

## Tech Stack

Backend:** C#, .NET 8, ASP.NET Core MVC, Entity Framework Core

**Database:** Microsoft SQL Server

**Frontend:** HTML, CSS, JavaScript, Bootstrap

**Authentication:** ASP.NET Core Identity

**AI & Machine Learning:** Ollama, Gemma 3, ML.NET

**API & Testing:** REST API, SoapUI, Unit Testing

## Architecture

The application follows a monolithic ASP.NET Core MVC architecture with logically separated controllers, models, data access, and service components to improve maintainability and code organization.
